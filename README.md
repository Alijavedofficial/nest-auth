# NestJS Production-Ready Auth

A battle-tested authentication boilerplate built with NestJS, featuring register, login, logout, and token refresh flows out of the box. Includes email verification and password reset via Redis-backed Bull queues, JWT access/refresh tokens, rate limiting, and secure password hashing. Designed with production concerns in mind: modular structure, DTO validation, exception filters, and environment-based config. Clone it, configure your env vars, and ship auth in minutes. Contributions welcome!
